# Locally hosted fonts

- Pretendard Variable: SIL Open Font License 1.1. Original project: https://github.com/orioncactus/pretendard. See `pretendard-OFL.txt`.
- Gowun Batang Regular: SIL Open Font License 1.1. Original source: https://github.com/google/fonts/tree/main/ofl/gowunbatang. See `gowun-batang-OFL.txt`.

Gowun Batang was losslessly converted from the original full TTF to WOFF2 with fontTools 4.66.1 and Brotli. All 12,494 mapped Unicode glyphs are retained, including all 11,172 modern Hangul syllables. No font subsetting was used. Browser styles and PNG export use only these local font files; there are no remote font requests.
