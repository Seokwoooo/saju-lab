# 사주 계산 엔진 검증과 한계

검증일: 2026-10-10. 런타임 계산은 `manseryeok@2.0.0`, 독립 런타임 비교는 개발 의존성 `lunar-javascript@1.7.4`를 사용한다. 해석은 계산값을 전통적인 상징으로 풀어 쓴 로컬 문장이다. 계산의 정확성과 성격·미래 예측의 타당성은 서로 다른 문제이며, 후자를 입증한 기능으로 설명하지 않는다.

## 서비스의 지원 범위와 선택한 관례

- 대한민국(`KR`) 출생 기록만 받는다. 입력 연도와 음력 변환 후 양력 연도 모두 **1909~2049년**이어야 하며, 변환된 양력 출생일은 **한국의 오늘 날짜까지** 허용한다. 현재 시각보다 늦은 오늘의 시간은 날짜 제한의 대상이 아니다. 한국 표준시 도입 전의 지방시 기록과 KASI 정본 이후의 추정 음력은 서비스 범위에서 제외한다. 라이브러리의 정밀 절입표 자체는 1800~2300년이지만 서비스의 출생 입력 범위를 더 좁게 제한했다.
- 입력된 당시의 벽시계 시각을 `Intl.DateTimeFormat`의 IANA `Asia/Seoul` 데이터로 UTC에 대응시킨다. 1909년 이후 사용된 UTC+8:30, +9:00 및 서머타임의 +9:30, +10:00 후보를 각각 역검증한다. 존재하지 않는 시각은 거부하고, 두 번 나타나는 시각은 두 후보를 모두 유지한다. 라이브러리 내부의 단순 역사시각 선택에 의존하지 않는다.
- **연주·월주:** 출생의 실제 UTC 순간을 입춘·월 절입의 UTC 순간과 비교한다. 음력 설날이나 양력 1월 1일에 연주를 바꾸지 않는다.
- **일주·시주:** 실제 순간을 **UTC+9 표준시로 환산**한 뒤 계산한다. 자정 **00:00**이 일 경계이며 23:00에는 일주를 바꾸지 않는다. 시주 천간도 같은 일간으로 계산한다. 지방 진태양시·출생지 경도·균시차 보정은 적용하지 않는다. 기록 시각을 그대로 쓰는 관례, 23시 일 경계, 진태양시를 쓰는 학파의 결과와 다를 수 있다. 이 선택을 보편적인 유일 정답으로 주장하지 않는다.
- 결과의 `solarDate`/`lunarDate`는 **기록된 출생의 달력 날짜**다. 일주·시주에 쓰는 환산 시각이 역사적인 보정 때문에 다음날/전날이 되면 경고를 표시한다.
- 시간 미상은 정오 등 임의의 한 시각을 정답으로 채택하지 않는다. 기록 날짜의 **1,440분 모두**를 확인하고, 각 분의 유효한 UTC 후보를 모두 계산한다. 모든 후보가 일치한 기둥만 확정한다. 시주는 항상 `null`, 대운은 항상 빈 배열이다. 입춘일에는 연주와 월주가 `null`일 수 있고 월 절입일에는 월주만 `null`일 수 있다.
- 현재 계약상 일주·일간은 필수다. 후보 간 일주까지 달라지는 역사 날짜의 시간 미상 입력은 **친절한 한국어 오류로 거부**한다. 임의의 일간으로 해석하거나 AI에 전송하지 않는다. 알려진 시간이 두 번 나타나면서 일주가 달라지는 경우도 거부한다. 일주가 일치하는 반복 시각에서는 확정된 기둥만 표시하고 `boundaryUncertain=true`, 대운 없음으로 처리한다.
- 계절은 월지 寅卯辰=봄, 巳午未=여름, 申酉戌=가을, 亥子丑=겨울이다. 월주 미확정 시 `절기 경계 미확정`이다.
- 오행 개수는 **확정된 천간·지지 글자 각각 1개**의 단순 합이다. 보통 8개, 시간 미상 6개이며 절기 경계에서는 4개 또는 2개일 수 있다. 지장간의 중복 가산, 계절 가중치, 신강약 판정, 용신 판정은 하지 않는다.
- 십신은 일간을 제외한 천간과 지지 본기의 관계를 센다. 합은 `elementTotal - 1`이다. 키는 비견·겁재·식신·상관·편재·정재·편관·정관·편인·정인 열 개만 허용한다. 지장간은 잔기·중기·본기 순서로 별도 표시하며 단순 오행/십신 합에 추가하지 않는다.
- 대운은 유일한 출생 순간과 남/여 방향 입력이 있을 때만 계산한다. 양남·음녀 순행, 음남·양녀 역행, 인접 절기까지 일수÷3의 반올림 시작 나이, 10년 구간을 사용한다. 방향 입력 미선택·시간 미상·반복 시각에서는 생략한다. 인생 사건이나 성공 여부를 예측하는 숫자로 사용하지 않는다.
- 세운은 한국 현재 연도를 기본 분석 연도로 정하고 그 해부터 5년간 계산한다. 각 세운은 그 해 입춘부터 다음 입춘까지를 뜻한다. `analysisYear` 인수는 재현 가능한 테스트를 위한 명시적 연도이며 1801~2295 범위를 받는다.

## 시간 미상 제한이 실제 적용되는 역사 구간

아래 날짜는 양력의 **기록 날짜**, 양 끝 포함이다. IANA 시각 후보 전수 확인으로 UTC+9 날짜가 둘 이상 나타나는 구간이다. 월 절입 여부와 무관하게 일주가 미확정이므로 정확한 시간 확인이 필요하다. 과거 출생 전체를 거부하는 규칙은 아니다.

| 기록 날짜 구간 | 원인 |
| --- | --- |
| 1909-01-01~1911-12-31 | 당시 +8:30에서 +9:00 환산 시 23:30 이후 다음날 |
| 1948-06-02~1948-09-12 | +10:00 서머타임에서 +9:00 환산 시 자정 직후 전날 |
| 1949-04-04~1949-09-10 | 같은 서머타임 보정 |
| 1950-04-02~1950-09-09 | 같은 서머타임 보정 |
| 1951-05-07~1951-09-08 | 같은 서머타임 보정 |
| 1954-03-20~1961-08-09 | 표준시 +8:30 및 해당 기간 서머타임, 1954-03-20 반복 시각 포함 |
| 1987-05-11~1987-10-11 | +10:00 서머타임에서 +9:00 환산 |
| 1988-05-09~1988-10-09 | 같은 서머타임 보정 |

서머타임 시작일의 사라진 한 시간은 유효한 후보에서 제외한다. 예를 들어 1988-05-08의 시간 미상 입력은 남은 모든 유효한 시각의 일주가 같아 지원한다. 1961-08-10 00:00~00:29, 1988-05-08 02:00~02:59처럼 **알려진 시간이 존재하지 않는 경우**는 별도로 거부한다. 브라우저/Node의 IANA 데이터가 올바르게 제공되는 환경이 전제이며, 역사 기록 자체의 신뢰성까지 검증하지는 않는다.

| 입력 | 공식 반환값 | 출처 |
| --- | --- | --- |
| 양력 1992-10-24 | 음력 1992-09-29 평달, 일진 계유(癸酉) | [KASI 양력 조회](https://astro.kasi.re.kr/life/solc?yyyy=1992&mm=10&dd=24) |
| 음력 1992-09-29 | 양력 1992-10-24 | [KASI 음력 조회](https://astro.kasi.re.kr/life/lunc?yyyy=1992&mm=09&dd=29) |
| 음력 2023-02-01 평/윤 | 평달=2023-02-20 기유(己酉), 윤달=2023-03-22 기묘(己卯); 윤2월 29일 | [KASI 음력 조회](https://astro.kasi.re.kr/life/lunc?yyyy=2023&mm=02&dd=01) |
| 양력 1997-02-08 | 음력 1997-01-01 평달 | [KASI 양력 조회](https://astro.kasi.re.kr/life/solc?yyyy=1997&mm=02&dd=08) |

KASI의 달력 화면에 표시되는 음력 월건·년간을 사주의 절기 월주·입춘 연주로 그대로 취급하지 않는다. 한국과 중국의 음력이 다른 날짜도 있다. 1997년 한국 설날은 2월 8일이며 `lunar-javascript`의 중국 음력 설날은 2월 7일이다. 그러므로 한국 음력 입력의 정본은 `manseryeok`의 KASI 기반 표와 공식 조회이며, 중국 음력으로 덮어쓰지 않는다.

## 자동 검증 증거

`tests/saju.test.ts`는 고정된 KASI 달력·일진, 평달/윤달, 2월 29일, 존재하지 않는 날짜, 정확한 분의 절입, 자정 관례, 시간 미상, 역사 시각, 범위, AI 최소 계약을 검증한다. `tests/local-reading.test.ts`는 실제 계산값에서 9개 풀이와 궁합이 파생되는지, 증거 표시·불확정 안내·대운 생략·점수 미조작을 검증한다.

- 입춘: 2024-02-04 **17:27 KST**의 -1분/정각/+1분. 연주 癸卯→甲辰, 월주 乙丑→丙寅.
- 경칩: 2024-03-05 **11:23 KST**의 -1분/정각/+1분. 월주 丙寅→丁卯.
- `lunar-javascript`의 절입 기준은 UTC+8이므로 연주·월주 비교에는 동일 순간의 중국 시각을 사용한다. 일주·시주는 선택한 UTC+9 표준 시각을 별도로 사용한다. 23시의 학파 차이를 독립 라이브러리 결과로 숨기지 않고 자정 관례를 고정값으로 검증한다.
- 독립 런타임 비교 사례: 1992-10-24 05:30, 1954-04-01 14:00(+8:30), 1961-08-09 23:45(+8:30, 환산 다음날), 1988-07-01 13:30(+10:00), 입춘 전후 및 경칩 전후 각 1분.
- 정밀 절입표는 라이브러리 소스상 `lunar-javascript` 천문 계산에서 추출한 보정표다. 따라서 두 런타임의 일치가 완전히 독립된 천문 관측의 재검증을 뜻하지는 않는다. 표의 분 단위 정밀도를 넘어선 초 단위 정확도·모든 연도의 KASI 절입 실측 일치를 이 작업에서 주장하지 않는다.
- 첫 실행: 구현 전 스텁에서 34 실패/16 통과(총 50). 엔진 구현 후 로컬 풀이 5개는 별도로 `로컬 해석 구현 전`/`궁합 구현 전` 오류를 확인했다.
- 최종 집중 실행: `npm test -- --run tests/saju.test.ts tests/local-reading.test.ts` → **61 통과**, 2개 파일 통과. 미래 생일은 한국 현재 날짜와 비교하며 음력·윤달은 변환된 양력 날짜를 비교한다. 한국 자정의 UTC 날짜 차이와 2049년 지원 범위는 명시한 테스트 시계로 확인한다. 로컬 풀이의 모든 공개 문장에서 한자·사주 전문 용어를 제외하고, 계산 근거는 별도 필드에 남기는 회귀 검사를 포함한다. Node에서 Vitest 로더의 `DEP0205 module.register()` 사용 중단 경고가 발생하며 테스트 실패는 아니다.

## AI 정보 경계와 해석

`AIProfile`은 새 객체로 만들어 날짜·이름·성별·출생 시간·분·원본 입력을 포함하지 않는다. 일간 오행/음양, 확정 기둥에서 집계한 오행·십신, 계절, 시간 존재/경계 불확정 여부, 대운의 나이 구간/오행, 세운의 분석 연도/오행만 포함한다. 천간·지지의 실제 글자, 전체 만세력, 경고문에 든 역사 날짜도 AI 프로필에는 넣지 않는다. 프로필의 분석 연도는 출생 연도가 아니다. 프로필과 화면 데이터의 집계 객체는 참조를 공유하지 않는다.

로컬 해석은 일간 오행·음양, 오행 개수, 십신 묶음, 계절, 실제 대운·세운을 증거로 표시한다. 무작위 문장·과장된 궁합 점수·질병·투자 수익·확정된 미래 사건을 만들지 않는다. 이 엔진 검증은 외부 AI 응답의 보안/품질, 브라우저 UI, 공유 PNG, 배포를 검증한 것으로 확대하지 않는다.
