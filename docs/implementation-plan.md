# 사주랩 구현 및 검증 계획

사용자의 2026-10-10 개발 지시서를 실행 기준으로 삼는다. 기존 `../redesign` 서비스는 보존한다. 새 독립 폴더, 새 Sites 프로젝트, 별도 공개 GitHub 저장소를 사용한다.

## 모듈 경계
- `lib/contracts.ts`: 입력, 실제 계산 결과, 최소 AI 입력, 해석 출력 계약.
- `lib/saju.ts`: 고정 버전 manseryeok 2.0.0, 한국 출생 계산과 범위/경계 검증. 시간 미상은 임의 시주 생성 금지.
- `lib/local-reading.ts`: 실제 계산에서 파생되는 로컬 기본 풀이 및 두 사람 궁합. AI 여부 명시.
- `components/` 및 `app/page.tsx`: 한국어 모바일 우선 흐름, 오행 캐릭터, 접힌 전문 데이터, PNG 카드.
- `lib/server/` 및 `app/api/`: OpenRouter Azure BYOK 우선, 명시적 GPT-6 Luna 폴백, JSON 검증, 취소, D1 원자적 제한.
- `db/schema.ts`: 출생정보 없는 단기 남용 방지 해시, 예산 카운터와 동시 호출 임대만 저장.

## 작업 순서와 증거
1. 계정 UI에서 Azure 설정, 적용 모델, BYOK 필터/공유용량 폴백, 데이터 정책을 확인한다. 키·자격증명은 출력하지 않는다.
2. 엔진 테스트 먼저: 양력/음력/윤달/윤년/입춘/월절입/자정/시간미상/한국 역사시각/지원범위. 독립 달력 결과와 비교한다.
3. 크림·핑크·세이지 팔레트, 독창적인 오행 캐릭터, 폼→기본결과→선택적 AI→공유의 완결된 흐름을 구현한다.
4. API 테스트 먼저: PII 차단, 원자적 비용·속도·동시성 제한, BYOK 경로 증거, 명시적 fallback, 타임아웃, 크기, 오류, 출력 검증. 모델 응답은 계산값을 덮어쓰지 못한다.
5. 6종 카드 1080×1350/1920, PNG와 동일 미리보기, 이름 기본 숨김, 국내 폰트 자체 호스팅. 두 명의 실제 계산 기반 궁합.
6. 타입·린트·단위·통합 테스트와 데스크톱/모바일 브라우저 QA, 이미지 실파일 검사를 진행한다.
7. 비밀값 검사 후 MIT 공개 저장소, 실제 주소/개인정보 안내/FAQ/SEO를 완성한다. 배포 성공 후 주요 흐름과 기존 사이트 보존을 검증한다.

## 검토 초점
- 시간 미상의 절기일 결과를 정답 하나로 확정하지 않는다.
- 한국 표준시·서머타임과 자시 관례가 문서 및 코드에서 일치한다.
- 공유용량 응답을 Azure BYOK 성공으로 표시하지 않는다.
- AI 실패·한도 초과 후에도 로컬 결과는 유지하며 AI 완료로 표시하지 않는다.
- D1에는 출생정보·결과·원본 IP가 들어가지 않고 짧은 TTL만 사용한다.
- 공유 PNG·URL·localStorage에 출생정보가 남지 않는다.
